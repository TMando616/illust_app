## 現在地

- プロジェクトの土台ができた（仕様書のステップ2を先に済ませた形）。アプリ本体・`IllustrationKit` パッケージ・試作用のコマンド `IllustPrototype` の3つ

## ステップ1の試作（2026-11-22 1回目）

- 処理の流れ：縮小（長辺1024px）→ 平滑化（桑原フィルター）→ k-means で色の番号を振る → 小さな粒・小さな面を隣にまとめる → 面ごとの平均色で塗る → 色の差がはっきりした面の境目に線
- 仕様書との違い：色数を減らした「代表色」で塗ると、背景の大きな面に色を取られて肌などの色がずれた。色数を減らすのは面の分け方を決めるためだけにし、塗る色は面ごとの平均色にした（本人に相談中）
- 速さ：Mac（リリースビルド）で1枚約0.1秒。仕様書の目安（保存時2秒以内）には余裕がありそう。実機では未計測
- サンプル写真：`samples/photos/`（Unsplash License、git には入れない。出典は `samples/CREDITS.md`）。実行：`cd IllustrationKit && swift run -c release IllustPrototype ../samples/photos ../samples/output --palette-from ../samples/style`
- 苦手：黒い犬のような暗い被写体は、線と塗りが同じ暗さで潰れる。木目などの細かい模様は、まだ迷彩柄のように割れる

## 試作2回目（2026-11-22）

- 本人の希望：線の太さは1回目のまま／デフォルメ（特徴だけ残してイラストっぽく）／パステル寄り
- デフォルメ：面の分け方を長辺400pxに縮めた画像で決め、元の大きさに戻してから境目を丸める（`segmentationLongSide`・`shapeRounding`）。小さな面は隣にまとめるが、隣との色の差が大きい面（サングラスなど）は特徴として残す（`keepContrast`）
- パステル：面の色の明るさを0.45〜0.95に寄せ、鮮やかさを少し抑える（`Pastel`）。灰色に色味を足すと黒い犬が紫に転んだので、鮮やかさは足さない
- 速さ：Macで1枚約0.2秒
- 苦手（残り）：暗くて模様の少ない被写体（黒い犬）は、目鼻などの特徴が消えて形だけになる。顔の目鼻も、写真によっては消える

## 試作3回目（2026-11-22）

- 2回目への本人の感想：「人も犬も形を残せていない」。色の近さだけで面をまとめていて、何が被写体かを知らないのが原因
- 変えたこと：
  - Vision の被写体の切り抜き（`VNGenerateForegroundInstanceMaskRequest`、iOS 17 / macOS 14〜）で被写体のマスクを取る。被写体は細かめ（長辺640px で面を分ける）、背景は大胆（220px）に単純化し、背景には線を引かない
  - 被写体の中の線は、色の境目ではなく明るさの変化から拾う（XDoG）。拾う前に被写体の中の明るさの幅を広げるので、黒い犬でも目鼻が出る
  - 被写体の外形に、少し太めの輪郭線を引く
  - A（全体をイラストに）と B（被写体だけ、背景は白）の2つの画風を用意し、本人に比べてもらっている
- 速さ：Mac で1枚0.2〜0.4秒
- 注意：被写体の切り抜きは、iOS シミュレーターでは動かない可能性がある（見つからないときは全体を被写体として扱う）。実機で確認する
